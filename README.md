# تطبيق مدير الاختبارات والدرجات للمدرسين

تطبيق Flutter متكامل لإدارة الاختبارات والدرجات والطلاب للمدرسين، يعمل بدون إنترنت بشكل كامل.

## المميزات الرئيسية

- ✅ إدارة المدارس والصفوف والمواد
- ✅ إدارة الطلاب مع استيراد من Excel/CSV
- ✅ إنشاء اختبارات احترافية
- ✅ محرر أسئلة متقدم مع دعم المعادلات الرياضية
- ✅ بنك الأسئلة
- ✅ نماذج اختبارات متعددة (A, B, C, D)
- ✅ توليد PDF احترافي
- ✅ إدارة الدرجات والحسابات التلقائية
- ✅ الواجبات والحضور
- ✅ التقارير والإحصائيات
- ✅ النسخ الاحتياطي والاستعادة
- ✅ دعم كامل للغة العربية RTL
- ✅ الوضع الليلي

## التقنيات المستخدمة

- **Flutter**: إطار العمل الرئيسي
- **Provider**: إدارة الحالة
- **Drift**: قاعدة البيانات المحلية
- **GoRouter**: التوجيه
- **PDF**: توليد الملفات
- **Flutter Math**: المعادلات الرياضية

## البنية المعمارية

يتبع التطبيق بنية نظيفة (Clean Architecture) مع فصل الطبقات:
lib/
├── app/ # تهيئة التطبيق
├── core/ # المكونات المشتركة
└── features/ # الميزات الرئيسية
├── data/ # طبقة البيانات
├── domain/ # طبقة المنطق
└── presentation/ # طبقة العرض


## التثبيت والتشغيل

1. تثبيت Flutter SDK
2. تثبيت الاعتماديات:
   ```bash
   flutter pub get
   ```
توليد كود قاعدة البيانات:

```bash
flutter pub run build_runner build
```
تشغيل التطبيق:

```bash
flutter run
```
المتطلبات
Flutter SDK >= 3.0.0

Dart SDK >= 3.0.0

Android Studio / VS Code
